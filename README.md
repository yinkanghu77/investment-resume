## 内容定位

- 产业研究：将行业趋势、竞争格局和产业链关系转化为企业端项目筛选问题。
- 战略与产业投资：围绕项目技术、商业化、资源匹配和风险组织评估材料。
- 投后管理：由经营信息整理延伸至订单、盈利质量和治理事项跟踪。

项目角色以实际承担的工作为准，不将材料准备等同于投资决策权，不将立项等同于完成投资。

## 维护约定

Markdown 是内容源；Word/PDF 后续由审核后的简历生成。中文与英文保持事实一致，按岗位修改侧重点，不扩大职责或成果。联系方式、准确任职日期、量化成果及教育信息确认后再完善投递版。

本仓库为个人求职材料，不代表任职公司的观点或投资建议。
